这些操作在所有 App 中都可用。App 专属映射只覆盖对应页面明确列出的按键。

| 手柄控制 | 默认动作 | 说明 |
| --- | --- | --- |
| <kbd>左摇杆</kbd> | 移动鼠标 | 直接、连续移动 |
| <kbd>右摇杆</kbd> | 滚动页面 | 上下滚动 |
| <kbd>A</kbd> | 鼠标左键 | 按住可拖拽、框选 |
| <kbd>X</kbd> | 鼠标右键 | 按住可右键拖拽 |
| <kbd>Y</kbd> | 语音输入 | 轻击物理右 Alt |
| <kbd>Y</kbd>，然后 <kbd>A</kbd> | 模拟回车 | 所有 App 都可用 |
| <kbd>十字键</kbd> | 方向键 | ↑ ↓ ← → |
| <kbd>LT</kbd> | 精准移动 | 降低鼠标速度 |
| <kbd>RT</kbd> | 快速移动 | 提高鼠标速度 |
| <kbd>RT + A</kbd> | 回车 / 确认 | 所有 App 中立即执行 |
| <kbd>RT + B</kbd> | 退格 | 每次按下一次，不连发 |
| <kbd>RT + X</kbd> | Esc / 取消 | 可能停止应用正在执行的操作 |
| <kbd>RT + Y</kbd> | 查找 | Windows 为 Ctrl+F，macOS 为 Command+F |
| <kbd>LT + LB</kbd> | 上一个窗口 | Alt + Shift + Tab |
| <kbd>LT + RB</kbd> | 下一个窗口 | Alt + Tab |
| <kbd>Back + Start</kbd> | 紧急退出 | 按住 1.5 秒 |

:::tip[按住才能拖拽]
按住 A，再移动左摇杆，就像一直按住鼠标左键一样，可以框选文字、拖动窗口或选择一片区域。
:::

## 所有 App 都能语音后回车

按 <kbd>Y</kbd> 启动语音输入，说完并稍作停顿后再按 <kbd>A</kbd>。默认情况下，Y 后至少等待 2 秒，A 才能发送 Enter。CouchPilot 只负责触发操作系统的语音输入，拿不到麦克风或 VAD 事件，因此使用可配置的最短等待时间防止立即误发送；过早按 A 会被安全忽略，既不会回车也不会误点鼠标。移动鼠标、切换 App、按下其他控制、完成回车或超过等待时间，都会让 A 恢复为普通鼠标左键。

Codex 还额外支持轻按或长按 <kbd>B</kbd> 删除字符；这些专属编辑操作详见 Codex 页面。

语音序列生效期间，即使没有操作手柄，也会检测前台 App 的变化。离开原 App 后序列就会取消，切回来也不会恢复；如果之前能识别的前台 App 变得无法识别，也会取消序列。

## RT 编辑组合

先按住 RT，再按 A、B、X 或 Y。这组编辑操作对所有 profile 生效，每次按下执行一次，不会自动连发。RT+A 直接发送 Enter，无需先启动语音，也不等待两秒。RT+B 即使在语音后使用，也只退格一次；Codex 原来的语音后单按或长按 B 仍然支持连续删除。

明确按下扳机组合会结束 CouchPilot 的临时语音编辑状态，因此 RT+Y 打开查找后，下一次单按 A 不会意外变成回车。这不代表关闭操作系统的语音输入。Enter、Esc 和查找的实际效果取决于当前获得焦点的应用。

RT 仍保留鼠标加速，同时按住两个扳机时 LT 优先。组合在按钮按下时确定；按钮保持按住期间改变扳机，不会产生第二次动作，也不会改变正在进行的鼠标拖拽。

## App 专属映射如何覆盖

前台应用匹配到 profile 后，仅替换该 profile 声明的按键。例如浏览器中的 <kbd>RB</kbd> 会切换到下一个标签页，但摇杆移动、滚动、右键和语音输入仍然保持全局行为。

配置支持 `a`、`b`、`x`、`y`、`lb`、`rb`、`l3`、`r3`、`dpad_up`、`dpad_down`、`dpad_left`、`dpad_right`，可加一层 `lt+` 或 `rt+` 前缀。`voice+a` 和 `voice+b` 是独立的上下文序列，不能再叠加前缀。Back 和 Start 保留用于紧急退出；不支持的名称会在加载配置时明确报错，不再静默失效。

可以修改 `voice+b` 对应的动作。只有 `backspace` 会在长按时连发；其他普通动作每次按下执行一次，鼠标动作保留按住和释放语义，语音动作遵循配置中的语音模式。

把动作设为空字符串可以禁用指定映射，包括扳机组合。已禁用的组合不执行任何动作；只有未分配的组合才会回退到普通按钮功能。
